What Esc & Delete mean

Esc — first match wins
  1. Node/outline edit: cancel the drag in flight (stays in edit mode)
  2. Node/outline edit: exit the mode
  3. Active tool: cancel its chain / drag / preview
  4. Clear layer solo, leave the terrain panel
Delete / Backspace
  1. Outline edit: the selected vertex
  2. Wall/band edit: the selected stone or joint
  3. Otherwise: the selected shape(s)
Same idea everywhere: the innermost editing session claims the key first.
