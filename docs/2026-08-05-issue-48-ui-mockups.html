Neutral overlay language

Selection furniture is a target, not a brand moment: white strokes and handles with a near-black ink ring, the same double-line trick Inkarnate-style art uses for outlines. It carries zero hue, so it survives every biome and every future theme accent without a palette swap. Selected things get a double-ring (ink ring inside a white halo). The old purple gizmo and sky/amber node colors retire; nothing overlay-side ever reads from the theme.

1 · Context menus: one anatomy, per-type contributions

Every menu is built from the same five slots: identity header (what you hit, where it lives) → quick controls (type-specific embedded rows) → type verbs → shared verbs (duplicate, move to layer) → danger. Each child kind registers a builder that contributes rows for the middle slots; the menu renderer only knows row types (action, submenu, toggle, slider, swatches, thumb strip), never child kinds. Lights get sliders, assets get a swap strip, walls get wall verbs, and adding a new tool never touches the menu component.

3 · Node editing: pen-tool controls

Three pieces, all chosen: bigger shape-coded handles with a loud edit state, key hints that follow the node plus the full map in the status bar, and full pen-tool beziers. Curved edges become first-class: outlines carry optional per-vertex tangents, and everything downstream (walls, fog, Clipper2 booleans) consumes a flattened ring, so curves work everywhere straight edges do today.

The chip follows the selected node with its three most-used keys; the status bar holds the complete map. Both update contextually (nothing selected → "click a node · drag an edge · Esc to finish").

Pen-tool anchors + tangents CHOSEN · FULL BEZIERS

Photoshop pen semantics on shape outlines: click adds a corner anchor (square), click-drag adds a smooth anchor (circle) and pulls symmetric tangents, Alt-drag breaks a tangent pair, double-click toggles corner ↔ smooth, and dragging the middle of a straight edge bows it into a curve. Tangent arms render only for the selected anchor and its neighbors, so the outline never turns into spaghetti.

smooth anchor selected · round knobs = tangent handles · Alt-drag breaks the pair anchor 2 · smooth · Alt break · dbl-click corner

What full beziers buy: walls on curved rings

Wall stones already lay out by arc length, so a curved ring gets a real stone wall with no extra authoring: bend the floor outline and the wall, fog, and lighting follow. This is the piece that makes caves, riverbanks, and round towers feel drawn instead of segmented.

stones follow the flattened arc · same layout code as straight walls

4 · How it works: behavior spec

Green bullets are interaction rules; amber bullets are the engineering changes underneath them.

Context menus

  • Right-click never pans, never fires the active tool; it hit-tests, adjusts selection, opens the menu.
  • Object outside selection → becomes the selection. Object inside a multi-selection → selection kept, verbs apply to all; mixed types show intersection verbs only.
  • Slider rows edit the store live with one undo entry per gesture, same rule as gizmo drags.
  • Suggestion strip: nearest by asset tag/category; "More…" opens the full browser pre-filtered.
  • Row vocabulary as a typed union: action | submenu | toggle | slider | swatches | thumbStrip. Renderer switches on row type only.
  • Per-kind builders: registerMenu(kind, (ctx) => rows) where ctx = child, layer, selection, active tool. Shared verbs and the danger slot are appended by the menu builder, never re-implemented per type.
  • Capture point in useCanvasInput before tool dispatch; tools drop their ad-hoc button-2 no-ops.
  • Locked/hidden layers render verbs disabled, mirroring the layer-panel rules.

Transform

  • Corners = uniform scale (Shift frees ratio). Pills = one-axis stretch. Rotate handle explicit, 15° snap, Shift frees.
  • Flip H/V = negative scale, via bar, menu, panel, and Shift+H / Shift+V.
  • Arrow keys nudge one grid square; Shift+arrows a quarter square. Ctrl+D duplicates with the paste offset.
  • Floating bar hides during any drag and near screen edges clamps into view; "…" opens the context menu.
  • Repro pass first: "doesn't work at all" is unverified; test per handle × child type in the browser before rewiring.
  • childTransform.ts:125-134: split scalar scale into scaleX/scaleY for assets/text; allow negative for flip.
  • One undo entry per gesture stays (existing CompositeCommand path).

Nodes + overlays

  • Handles 11px visual, ≥20px hit. Edit mode: rope-dash outline, map dims 15%, status bar names mode and keys, chip follows the node.
  • Pen semantics: click = corner · drag = smooth · Alt breaks tangents · dbl-click toggles · edge-drag bows a straight edge into a curve · tangents only on selected + neighbors.
  • Delete refuses below 3 points with a status-bar notice, not a silent no-op. Esc order stays: cancel drag, then exit.
  • Overlay palette is theme-free by design: white/ink constants in one module shared by gizmo + node overlays. Retire 0x6c63ff, 0x38bdf8, 0xfbbf24. Chrome accent stays themeable app-side and never leaks onto the canvas.
  • Schema: optional per-vertex in/out tangents; absent tangents = straight edge, so every existing shape stays valid untouched.
  • Flatten once per edit (fixed world-unit tolerance) into straight rings for Clipper2 / walls / fog; stone layout already parametrizes by arc length, so curved rings reuse it.
  • Insert-on-curve splits with de Casteljau so the outline shape is preserved exactly; curve hit-testing projects the cursor to the flattened ring.
  • Floor-ring edits keyed by ring index (floorWallEdits) can silently retarget after shape edits. Decide this session: fix or document, don't leave it implicit.
