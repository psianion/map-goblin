What this replaces

The Achromatic Shell, retired

The current system has a name and a stated premise. canvas/tailwind.config.ts calls it the “Achromatic Shell” and comments that the accent is achromatic “so colour never becomes the only state encoding.” Moss breaks that premise deliberately, so the guarantee has to be kept another way — shape-encoded state, below.

Reality in the codeConsequence for this system
Two token vocabularies, duplicated in both apps: the Tailwind theme (surface-0…3, text-*, border-*, accent-*) and the shadcn CSS variables. A revalue touches four files, not two. The names below are the Tailwind ones because that is what components actually reference; the shadcn block maps onto them one-for-one.
The runner's index.css hard-codes one dark theme on :root, with a comment explaining the table has only one theme on purpose. Day mode makes that comment false. The runner needs a light block it has never had, plus a switch and a stored preference.
Sonner toast overrides hard-code a blue-grey palette — rgba(19,19,26), #B0B0C0, rgba(42,42,58) — matching neither vocabulary. Toasts are outside the system today. The pill below keeps sonner's shape and radius but takes its colour from tokens.
Kbd uses bg-surface-2, border-border-subtle, text-text-secondary — the second of those resolves only because the theme key is literally border-subtle. Worth a grep pass for other near-miss class names while the values are being changed anyway.

Found while building

Loose ends worth a decision

IssueDetail
Typeface split across apps Canvas pulls Cinzel, Raleway and Space Mono from the Google Fonts CDN; the runner refuses webfonts on purpose so a live table never waits on a CDN. Right now the two apps literally render in different faces. Either self-host one shared face for both, or drop to system sans everywhere and keep a display face for marketing only. Recommendation: self-host one text face, system stack as the fallback, display face never in-app.
Radius disagrees with itself --radius is 0.25rem (4px), but button.tsx uses rounded-lg and references --radius-md, which is not declared in either app's block. Buttons above use 6px, controls 4px, chips 2px — pick a scale and declare all three.
Sonner is outside the system Hard-coded blue-grey pills with per-type border tints in raw rgba. The pill shape is good and worth keeping; the colours should come from tokens.
Semantic success equals the accent Accepted deliberately, with shape carrying presence state instead. Worth confirming you agree rather than discovering it later.
Contrast needs a real check Day-mode text-muted on surface-1 is the tightest pair here and lands close to 4.5:1. It should be measured against PRODUCT.md's ≥4.5:1 commitment before this ships, not eyeballed.
Sprint 3 is mid-flight The branch is paused before its verification gate. Retheming both apps now would churn the visual E2E baseline and muddy that gate — this belongs on its own branch after Sprint 3 closes.
