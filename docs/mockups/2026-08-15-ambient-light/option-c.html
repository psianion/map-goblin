Ambient light · P0 mockups · 2026-08-15 · Option C of the round

Option C — Almanac card

Legibility of the effective state is the hero; controls are secondary. The Table's World block opens with one card that reads like an almanac line (what time it is, what is in the sky, what that resolves to), with the effective-state badge as its centrepiece and the coupling written out underneath as a single sentence. The Editor's Environment section is split into the feature's three real layers: mood, time of day, sun & moon, each summarised in one line before it is opened.

A DM who only ever reads these two surfaces should end up understanding the coupling model without being taught it. Progressive disclosure is deliberately incomplete: the clock is draggable at rest and the darkness override sits on the card face. Nothing a DM needs mid-session is more than one interaction deep.

Editor = Moss tokens, 300px overlay panel Table = Achromatic Shell, 256px sidebar Map art: Fieldstone Keep, graded per state Override switches, disclosure and the day-scrub are live

0Shared vocabulary

Three glyph families, defined once and reused on both surfaces. Every one of them is paired with a word: no state in this design is encoded by colour alone, because the Table's palette is achromatic by contract and a DM reads these in a dim room under time pressure.

Effective gate

DaylightFull disc. Normal sight, no clipping.
DuskHalf disc on a horizon. Sight normal, mood dimmed.
DarknessBroken ring. Players see only what a light covers.

Night sky

Full moonFilled. Gate lands on dusk; soft silver shadows.
CrescentSliver. Darkness with a softened bite; weak shadows.
MoonlessStruck circle. Full bite, no directional shadows.

Provenance

AutoClock glyph, outline chip. The rule produced this.
OverridePadlock, filled chip. You set this; the clock is ignored.
Not applicableStruck dash + a reason in words. Never a bare grey control.

Reading the trace

Outdoor → Night → Crescent → Darkness One line under the badge, drawn straight from the plan's coupling table: the inputs on the left, the resolved gate on the right. When an override is engaged the whole trace is struck through and a second line replaces it: the model stays visible, but it visibly stopped deciding.

1Table — “World” block Almanac card

256px DM sidebar, Achromatic Shell tokens, no card chrome around the block itself (matching the shipped Environment block). The one bordered box inside it is the almanac card, because that is the thing being read. Anatomy, top to bottom: almanac line (what is happening in the world), effective badge (glyph + word + consequence), coupling trace (why), override (the one control that lives on the card face), then the quiet row: clock always draggable, everything else one click away. Six states below walk the whole coupling table.

Why the override lives on the card. The brief's own risk with progressive disclosure is burying a mid-session control. Two things are exempted from the fold: the clock, a slider already drag-ready in the collapsed row (zero interactions), and the darkness override, a switch on the card face (one interaction, and the same interaction that changes the card also changes the card's border, chip, and trace). Sky and speed are genuinely set-once-per-scene, so they fold. The switches on this page are live: click any “Darkness override” to watch all five signals move together.

Achromatic by contract, and it costs nothing. Every state above is legible in greyscale: gate = glyph shape + word, provenance = filled vs outline chip + padlock vs clock + word, override = struck-through trace. The clock track is a luminance ramp rather than a sunrise gradient, because hue belongs to the canvas and chrome stays quiet (PRODUCT #1). text-muted #666 is 3.3:1 on surface-0, so it is used only on disabled/not-applicable affordances; every readable line uses #999 (6.6:1) or brighter.

Copy rules used. Almanac lines state a fact and its consequence, never a mood (“Night — crescent moon, faint light”, not “The moon hides her face”). Badge sub-lines name who is affected (“players only”) because the DM's own view never changes. Nothing in the Table copy is longer than the 256px column at 12px.

2Editor — “Environment” section Three layers

300px properties panel, Moss tokens, sitting where AmbientSection sits today (last card in the stack, after Grid). The section is organised as the feature's three actual layers — 1 Mood, 2 Time of day, 3 Sun & moon, numbered because they genuinely compose in that order. Each shows one line of its current contribution when closed, so the whole section can be read shut. Environment type sits above all three because it governs which of them apply, and the auto-gate consequence is spelled out as a row rather than left to be inferred.

What each Editor control reuses. Mood presets are the shipped AMBIENT_PRESETS row unchanged (same six hexes, same 24px circles, same border-accent-active on the active one) — it is being promoted, not redrawn. Keyframes are five ColorChip-triggered ColorFields in a strip. Natural light is ToggleSwitch. The scrub is SliderInput's live-drag/commit-on-release idiom with tick labels drawn on top. Only the compass is genuinely new geometry.

The edited-keyframe mark. A recoloured keyframe gets a moss border and a ✎ in its label, so “this preset has been overridden” survives greyscale and the 7px label size. It matches the Table's auto-vs-override grammar: the system's value versus yours, marked the same way on both surfaces.

3The canvas underneath

One crop of Fieldstone Keep, six states. Grade is a multiply wash with a vertical fall-off (painted, not a flat neutral overlay); the three brazier pools are a screen layer whose colour never changes; shadow quads extrude along one vector in every frame, with length and alpha set by time and sky. This is what both panels are describing.

4Engineering notes

  • Table. New session/client/src/modules/world/WorldPanel.tsx, registerPanel({ roles:['dm'], order:1 }). Lift Segmented and Switch out of FogTool.tsx into components/ui/ first: this is their second consumer. Sky and speed are Segmented; the override is Switch with a card-level data-engaged hook for the border/chip/strike states. Semantic tokens, not SessionControls.tsx's raw neutral-*.
  • Wire pattern. Clock/sky/speed/override go through the existing set-environment-style optimistic-echo (pending value + 4s fallback timeout, cleared on broadcast and on scene switch). The almanac card renders from the resolver output, so a pending clock value must feed the resolver too or the card will disagree with the slider for one round trip.
  • One resolver, one card. The card's three lines are literally resolve(environment, clock, sky, override) → { line, gate, biteLabel, provenance, trace[] }. Shared pure module, server + both clients. Nothing in the panel computes coupling locally.
  • Badge in two places. TableStatusBar's envLabel should become a thin consumer of the same resolver output (keeping its "omit the default" rule: no chip when gate is daylight and provenance is auto). Card and status bar must never disagree.
  • Editor. EnvironmentSection absorbs AmbientSection; sub-section open state joins rp-sections in localStorage. Mood/keyframe edits use the existing live-set + commit-on-release undo idiom. The preview clock is component state only — it must not touch the store, or an undo entry, or any command.
  • Compass. New control: 52px dial, pointer-drag with 15° snap on Shift, arrow keys ±1°, numeric entry as fallback. Canvas-space gizmo (if any) stays white+ink, never moss.
  • Cost of the trace. Four short strings per state change; it re-renders on clock ticks. With time-speed on "fast" the clock steps coarsely (minutes granularity per plan), so this is not a per-frame cost. The card should still memoize on the resolver output, not on the raw clock.
  • Not solved here. Indoor damping has no visual in this option (only outdoor and underground are drawn); an indoor frame would sit between them with a damped grade and the same "auto gate: off" row.
